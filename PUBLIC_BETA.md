# Calamus 0.1.0-beta.1

Публичная тестовая сборка неофициального клиента на Telegram API, основанного на Telegram 12.10.6 и Cherrygram 11.3.0. Пакет: `ksnxdev.calamus`, versionCode: `1`. Обновления: https://t.me/CalamusGram. Исходники и выпуски: https://github.com/ksnxdev/Calamus.

## Сборка

Нужны Java 21, Android SDK/platform 36, build-tools 36.0.0, NDK 27.2.12479018 и CMake 3.22.1. Для Git-копии сначала выполнить `git submodule update --init --recursive`; в архиве исходников содержимое подмодулей уже включено.

Скопировать `local.properties.example` в приватный `local.properties`, указать путь SDK и свои `TELEGRAM_API_ID` / `TELEGRAM_API_HASH`. Для подписи использовать собственный ключ: заполнить отдельный файл по образцу `calamus-signing.properties.example` и передать его путь через переменную окружения `CALAMUS_SIGNING_PROPERTIES`. Файл с паролями и ключ не следует размещать в публичных исходниках.

```bash
export JAVA_HOME=/path/to/jdk-21
export CALAMUS_SIGNING_PROPERTIES=/private/path/calamus-signing.properties
./tools/build-beta.sh --console=plain
```

Телефонный APK: `TMessagesProj_App/build/outputs/apk/afat/standalone/Calamus-0.1.0-beta.1-standalone-universal.apk`. Вариант `standalone` подписывается постоянным ключом, использует R8 и сокращение ресурсов, `debuggable=false` и `DEBUG_VERSION=false`. Обычное диагностическое логирование выключено по умолчанию; явно включённая пользователем диагностика может сохранять журналы локально. Сборка с `-Pcalamus.emulator=true` содержит x86_64 и предназначена только для эмулятора.

## Установка и ограничения

Для первой публичной беты создан новый ключ. Тестовые APK 71410 и более ранние подписаны другим сертификатом: перед установкой беты требуется их удалить и затем снова войти в Telegram. Удаление приложения стирает его локальные данные; секретные чаты и локальные архивы не восстановятся из облака. Прежде чем удалять старую версию, проверьте, какие локальные данные нужно сохранить. Облачная история Telegram и локальные данные приложения — разные вещи.

Телефонная сборка содержит ARM64 и ARMv7. Минимальная версия — Android 7. Python-плагины доступны с Android 10, меню сообщений в стиле iOS — с Android 11. Private View устанавливается отдельно и по умолчанию не включён.

Проверки эмулятора не заменяют испытаний реального аккаунта. Серверная авторизация, 2FA, реальная доставка медиа, звонки, истории, видимость призрака с другого аккаунта и уведомления после выгрузки пока не подтверждены полным сквозным тестом. Собственный FCM-проект пока не настроен; доставка в фоне требует отдельной проверки на телефонах. Бета предназначена для пользователей, готовых сообщать об ошибках.

Изоляция плагинов ограничивает прямой доступ к устройству и аккаунту, но не обещает безвредности любого стороннего плагина. Будьте внимательны к выдаваемым разрешениям и чатам. Внешние интеграции и сведения о локальных данных описаны в приложении: Calamus → О Calamus → Политика конфиденциальности.

Сохранены функции Cherrygram и API Private View. Соответствие всего набора функций Telegram ToS не подтверждается: управление отображением статуса, реклама и внешние интеграции требуют отдельного рассмотрения. Правила: https://core.telegram.org/api/terms.

## Комплект публикации

APK, архив соответствующих исходников, `SHA256SUMS.txt`, описание версии и результаты проверки следует размещать вместе. Не публикуйте каталог подписи, `local.properties`, `calamusapi.txt`, резервные копии данных или журналы переписок. Сохраняйте постоянный ключ подписи отдельно от исходников и его резервную копию: следующие обновления должны использовать ту же подпись.

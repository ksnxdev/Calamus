Private View 1.1.0 — изолированный Python-плагин для Calamus 71360+ (API 3), Android 10+.

Сначала установите новый APK Calamus, затем откройте Настройки → Плагины → Установить из файла и выберите Private-View.plug. В окне установки выберите чаты, которые нужно архивировать, и подтвердите показанные возможности. Без выбранных чатов события и архив этих чатов недоступны.

Плагин сохраняет текст и подписи сообщений, полученных этим клиентом при работающем плагине, и последующие полученные правки. При получении события удаления версия остаётся в отдельном локальном архиве и отмечается удалённой. История доступна через обычное контекстное меню сообщения → История изменений. Для удалённых сообщений используйте команду .deleted в соответствующем чате либо меню команд плагинов рядом со строкой ввода. Команды перехватываются локально и не отправляются собеседнику.

| Команда | Действие |
| --- | --- |
| `.archive` | Локальный архив текущего разрешённого чата |
| `.deleted` | Сохранённые сообщения этого чата, для которых получено удаление |
| `.history ID` | История сохранённых версий сообщения по ID |
| `.ghost on` / `.ghost off` | Включение и выключение управления присутствием для текущего аккаунта |
| `.ghost status` | Сохранённое состояние режима для текущего аккаунта |
| `.lastseen` | Доступный Telegram-статус пользователя текущего личного чата |

В настройках плагина есть сохранение новых сообщений и общий переключатель призрака для выбранных аккаунтов. Команда .ghost меняет выбранный аккаунт; последующее изменение общего переключателя применяет его ко всем разрешённым аккаунтам. Призрак изначально выключен.

При включённом режиме штатная отправка online при открытом приложении подавляется, отправляется собственный offline. Перед отправкой сообщения клиент запрашивает online, после подтверждения отправки или ошибки — offline. Для нескольких одновременно отправляемых сообщений окно остаётся открытым до последнего результата; отсутствующий результат закрывается по таймауту 30 секунд. Отключение/ошибка плагина, отзыв прав и выход освобождают управление. Полной невидимости это не гарантирует: итоговый статус задаёт Telegram, действия пользователя и другие открытые сессии аккаунта могут влиять на видимость. Реальное сетевое поведение на авторизованном аккаунте в автоматических проверках не подтверждено.

Точное скрытое время чужого захода плагин не получает и не вычисляет по косвенным признакам. .lastseen показывает последнюю доступную клиенту метку либо приблизительный статус. Telegram ограничивает взаимную видимость для аккаунтов без Premium; даже Premium не раскрывает время, которое собеседник скрыл от вас. Плагин не меняет ваши серверные настройки приватности и не подделывает подписку. [Описание Telegram](https://core.telegram.org/constructor/privacyKeyStatusTimestamp).

Архив находится в приватном no_backup-хранилище Calamus, отдельно для каждого плагина и с привязкой записей к Telegram user_id и чату. Изолированный Python не получает путь к базе, сеть, файлы аккаунта или произвольные Telegram RPC. Плагин не запрашивает разрешение отправки сообщений. Данные читаются через проверяемый брокер. Выход из аккаунта очищает его записи; удаление плагина удаляет его архив. Обновление самого плагина сохраняет архив, но требует повторного согласия с правами.

Ограничения: до 16 МиБ SQLite-базы и 20000 сохранённых версий на плагин; при заполнении удаляются самые старые записи. Секретные чаты, сообщения с TTL и исчезающие вложения не архивируются. Сами бинарные медиафайлы не копируются. Ранее удалённые сообщения и прежние правки, которые этот плагин не успел сохранить, восстановить невозможно. Архивирование зависит от работы Calamus/плагина и доставки событий; завершённый Android-процесс не может записывать сообщения. Ограничения очереди и частоты API сохраняются.

Проверки: tools/test-presence-host.py проверяет настоящий контроллер присутствия с подменённым окружением без RPC; tools/test-archive-emulator.sh проверяет настоящий CPython-плагин, доставку во время фонового asyncio-цикла, штатные NotificationCenter-события получения/правки/удаления, поток из 130 сообщений, SQLite, области доступа и экраны с синтетическими данными в изолированном эмуляторе с временно выключенной сетью. Информация о поведении Telegram-сервера требует отдельного прогона на тестовом аккаунте.

В версии 1.0.2 устранено отключение плагина при активном потоке сообщений: настройки сохраняются в памяти и обновляются по событию, ошибки лимита API безопасно обрабатываются. Лимит брокера 240 вызовов в минуту сохраняется; сообщения сверх этого предела могут не попасть в архив.

Для исправления ошибки Isolated worker is busy установите Calamus 71350: клиент теперь дожидается завершения фонового asyncio-цикла и затем доставляет событие. Изоляция, проверка сессий, watchdog и лимиты ресурсов сохранены.

В Calamus 71360 удалённые сохранённые сообщения остаются в обычном облачном чате: текст приглушён, рядом со временем стоит отметка «удалено». Они подгружаются из приватного архива после повторного открытия чата. В меню по аватарке / меню чата есть «Просмотреть удалённые»: архив со страницами и поиском по всему сохранённому тексту текущего чата, без учёта регистра, с одинаковым поиском ё/е. Поиск не ограничивается текущей страницей. Восстановленные вложения показывают сохранённую подпись либо тип вложения, бинарные файлы не архивируются. Для локальных удалённых сообщений доступны копирование и история; реакции, ответ, редактирование и пересылка заблокированы. При отзыве разрешений, отключении или удалении плагина его локальные сообщения скрываются. Встроенное отображение предназначено для обычной истории чата, без секретных чатов и отдельных веток обсуждений. Сам архив остаётся ограничен 16 МиБ и 20000 версиями; экран архива показывает все сохранившиеся записи, а для одного загружаемого диапазона чата подмешивается до 500 записей на плагин.
